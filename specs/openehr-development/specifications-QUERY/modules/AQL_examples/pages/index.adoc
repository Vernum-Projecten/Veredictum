= {spec_title} [.spec-status.spec-status-development]#{spec_status}#

Annotated AQL query examples covering common clinical retrieval patterns across EHR, Composition, Entry, and demographic contexts. Intended as a practical complement to the formal AQL specification. Examples range from simple single-archetype retrievals to complex multi-entry queries with joins, aggregations, and parameter substitution. Each example is accompanied by narrative explaining the clinical intent, the data model being queried, and notes on expected result sets.

== Purpose

This document documents examples of use of the openEHR Archetype Query Language (AQL).
