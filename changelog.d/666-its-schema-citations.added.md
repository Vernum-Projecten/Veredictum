- A citation may name a file of the released ITS-JSON or ITS-XML schema
  bundles (`specs/its-json-schemas/`, `specs/its-xml-schemas/`), and a JSON
  Pointer into a JSON or YAML source may name a number, a boolean or `null`,
  whose quote is that value written as JSON and is matched by value. No
  catalogue citation rests on an ITS-JSON schema yet: whether one may ground
  an expectation waits on an owner ruling (#842).
