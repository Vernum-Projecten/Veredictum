## aql-mix v1 (Provisional)

Query speed over one population, one set of percentiles per query class rather than one blended query number: the indexed point lookup, the single-EHR scan, the value filter, the cross-EHR population filter, the population COUNT, and the ordered page a paged interface reads.

- File: `aql-mix.yaml` (sha256 `122d18faa1f183fa8ffc5c5e6e0821c334a063a72bd0c500023d6b164dc6cba1`)
- Seed: 4706627057783240704; arrivals: Poisson; samples per plateau: 5000
- Corpus: POC (50 EHRs), 20 compositions per EHR
- Planned run after seeding: 255 to 590 s (limit 600 s)
- Reads per write: reads only; operations per interaction: 1.00
- Reproduces: The aql-mix bench pack, version 1.1.0: 50 EHRs each holding the community harness's Vital signs composition 20 times, seeded on 8 workers, and six AQL classes offered open-loop at equal shares. Its mix is the harness's, so the population read band does not gate it.
